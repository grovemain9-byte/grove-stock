# 2-B 手法スイッチ（regime 逆張り⇄順張り）— edge検証 Phase A（2026-06-14）

## 結論: **2-B（逆張り⇄順張り切替）は defer**（S1ゲートで弾いた）。代わりに「弱気で逆張り厚張り」を追う（Grove判定）。

## 問い
「もみ合い=逆張り / トレンド=順張り に自動切替すれば両相場で稼げる」という 2-B の賭け筋は、実データで実在するか？（建てる前のS1ゲート）

## 方法（既存infra reuse・本番非変更）
- 逆張り = 実戦略 backtest（`runner.run_backtest` 5年 2021-05〜2026-06、1571銘柄）→ `regime.label_trades_by_regime` + `regime_summary`
- 順張り = 素朴 momentum（Donchian 20日高値ブレイク + MA25上向き / trailing -8% or MA25割れ exit）同universe・同期間
- regime = `regime.classify_daily_regimes()` 日経3値（bullish/ranging/bearish、MA25乖離±3%+20dリターン）
- 独立検証: `nikkei_bars`(history_cache, 決定的) で別経路ラベリング → 完全再現
- script: `docs/grove-stock/research/2b_reversal_by_regime.py` / `momentum_by_regime.py`

## 結果（独立再現済）
| | 上げ(bullish) | もみ合い(ranging) | 弱気(bearish) |
|---|---|---|---|
| **逆張り** | **0件**（建てない） | 524件 勝率53% +0.4% | 210件 **勝率67% +3.4%** |
| **順張り** | 64件 勝率44% +3.7% | 277件 勝率42% +3.9% | 130件 勝率48% +2.6% |

## 読み
1. **逆張りは上げ相場で"そもそも建てない"** — P4(日経MA25乖離<0 必須、engine.py:283/371)が既に「上げで落ちるナイフを掴むな」を実装済。2-Bが埋めようとした「上げで逆張りが負ける穴」は最初から無い（P4が塞いでる）。
2. **順張り(素朴版)は上げで特に勝たない** — どのregimeも avg横ばい(CI全重複)、勝率<50%(コスト引いたら負け濃厚)。
3. → **切替の賭け筋は一次データで非支持**。

## 但し書き（kill断定でない）
- regime = 日経indexの粗い3値、個別銘柄の vol/slope「もみ合い/トレンド」軸では未測定（粒度ミスマッチ）。
- 順張りは未最適化・コストOFF。
- → 「edge完全に無い」でなく「**素直な版では出なかった**」。ただしP4が上げを既に塞ぐ事実は regime軸に依らず効くので、切替の上積みは薄い公算。

## 拾った宝（→ 次の追う対象）
**逆張りは弱気/パニックで圧倒的**（勝率67%/+3.4% vs もみ合い53%/+0.4%）。データが推すのは "手法切替" でなく **「弱気で逆張りを厚く張る」regime-conditional sizing**（2-Bより単純で強い）。
- **次のS1ゲート（最重要）**: 弱気で厚張りは **tail-risk を生き残るか？** 弱気=暴落局面でもあり、67%勝率の裏に致命的左尾(panic買いが反発しない数回=-50%)が隠れてないか。boat教訓(87%喪失)+R1警告(勝率過大推定)。**平均でなく最悪ケースで検証してから sizing を上げる。**
